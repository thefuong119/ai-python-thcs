HƯỚNG DẪN SỬ DỤNG NỀN TẢNG

Tác giả: Thầy Nguyễn Thế Phương - THCS Thành Đông, Tân Quới, Vĩnh Long

1. ĐĂNG NHẬP

  1. Nhấn nút "Học Sinh" hoặc "Giáo Viên / Admin" ở góc phải trên cùng.
  2. Nhập Tên đăng nhập (có thể dùng SĐT/Email/CCCD đã đăng ký) và Mật khẩu.
  3. Chưa có tài khoản? Nhấn tab "Đăng Ký Mới" và điền đầy đủ thông tin.
  4. Quên mật khẩu? Nhấn nút "Đổi password" trên thanh menu (khi đã đăng nhập) để đổi mật khẩu.

2. LÀM BÀI (THỰC HÀNH LẬP TRÌNH)

  1. Chọn tab "Thực Hành Lập Trình".
  2. Chọn bài tập từ dropdown (có thể tìm kiếm, lọc theo độ khó).
  3. Đọc kỹ đề bài bên trái. Ví dụ công khai hiển thị ngay bên dưới.
  4. ⚠️ Quan trọng: Nếu đề có test, bạn nên nhập dữ liệu vào ô "Dữ liệu vào (input.txt / stdin)" bên dưới editor để chạy thử chính xác với dữ liệu mẫu.
  5. Nhấn "Chạy Thử" để xem kết quả — kết quả hiển thị ở ô "Kết quả chạy" bên cạnh.
  6. Khi đã hài lòng, nhấn "NỘP BÀI CHẤM ĐIỂM" — hệ thống tự chấm với tất cả test (cả công khai và ẩn).
  7. Kết quả chi tiết từng test hiện trong thẻ "Kết Quả Chấm Điểm Tự Động".
Nhắc nhở: Nếu bài tập có test với dữ liệu đầu vào, hãy nhập dữ liệu vào ô input.txt trước khi "Chạy Thử" để kiểm tra. Không nhập thì kết quả có thể không đúng như mong đợi.

3. SỬ DỤNG AI ROBOT TRỢ LÝ

  1. Robot ở góc dưới màn hình có thể kéo thả đến bất kỳ vị trí nào.
  2. Nhấp 1 lần vào Robot → Robot đọc nội dung văn bản tại vị trí đang đứng.
  3. Kéo Robot đến đoạn văn bản cần nghe → Robot tự đọc.
  4. Nhấp lại khi Robot đang đọc → Dừng đọc.
  5. Bong bóng thông báo (toast) hiện phía trên Robot — nhấp vào để đóng nhanh.

4. HỎI GIA SƯ AI

  1. Trong tab Thực Hành, nhấn "Hỏi Gia Sư AI" góc trên khung đề bài.
  2. Chọn 1 trong 3 chế độ:
    • Socratic — Gợi mở để em tự tìm ra lời giải.
    • Hướng tiếp cận — Gợi ý thuật toán.
    • Phân tích lỗi — Chỉ ra lỗi trong code hiện tại.
  3. Đặt câu hỏi vào ô chat, nhấn Enter hoặc nút "Gửi".
  4. Nhấn nút gợi ý nhanh: "Soi lỗi code", "Tại sao sai?".

5. CĂN CHỈNH CODE

  1. Nhấn "Tab" trên thanh công cụ editor để thêm 4 dấu cách thụt lề.
  2. Nhấn "Format" để hệ thống tự căn chỉnh toàn bộ code đúng chuẩn Python.
  3. Nhấn biểu tượng Copy để sao chép toàn bộ code.

6. XEM CODE MẪU

  1. Trong tab Thực Hành, nhấn nút "Xem Code Mẫu" ở khung màu xanh đậm phía dưới editor.
  2. Hệ thống tự điền code mẫu vào editor để em tham khảo.
  3. ⚠️ Lưu ý: Trong "Bài Kiểm Tra Trực Tuyến", nút Xem Code Mẫu bị ẩn nếu giáo viên chọn không cho xem.

7. BÀI KIỂM TRA TRỰC TUYẾN

  1. Chọn tab "Bài Kiểm Tra Trực Tuyến".
  2. Chọn đề từ dropdown (chỉ hiện đề phù hợp với khối của em).
  3. Chọn từng câu hỏi để làm — mỗi câu làm xong nhấn "NỘP CÂU NÀY".
  4. Kết quả từng câu + tổng điểm hiển thị trong thẻ "Kết Quả Bài Kiểm Tra".

8. ĐỔI MẬT KHẨU / QUÊN MẬT KHẨU

  1. Nhấn nút "Đổi password" trên thanh menu (khi đã đăng nhập).
  2. Nhập tên đăng nhập + 1 trong 3 phương thức liên lạc đã đăng ký (SĐT / Email / CCCD).
  3. Nhập mật khẩu mới 2 lần → nhấn "Xác nhận đổi".
  4. Nếu xác thực sai → hệ thống ghi nhật ký Reset lại màu đỏ để Admin biết và khôi phục.
