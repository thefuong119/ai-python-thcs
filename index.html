HƯỚNG DẪN SỬ DỤNG NỀN TẢNG

Tác giả: Thầy Nguyễn Thế Phương - THCS Thành Đông, Tân Quới, Vĩnh Long

1. ĐĂNG NHẬP

  • Nhấn nút "Học Sinh" hoặc "Giáo Viên / Admin" ở góc phải trên cùng.
  • Nhập Tên đăng nhập và Mật khẩu. Nếu chưa có tài khoản, chọn tab "Đăng Ký".
  • Khi đăng ký, hãy nhập ít nhất 1 trong 3 phương thức liên lạc: SĐT, CCCD, Email.
  • Tài khoản dùng thử: hocsinh / Hocsinh@123 hoặc giaovien / Giaovien@123.

2. LÀM BÀI THỰC HÀNH

  • Chọn tab "Thực Hành" → chọn bài tập ở danh sách bên trái.
  • Đọc đề bài phía trên, sau đó viết code Python vào ô soạn thảo màu đen bên phải. Ô code không có số dòng để thoáng hơn.
  • Dữ liệu vào (stdin): Nhập số liệu test vào ô "Dữ liệu vào". ⚠️ Hệ thống sẽ nhắc nếu bạn quên nhập!
  • Nhấn "Chạy Thử" để xem kết quả nhanh ở ô "Kết quả".
  • Nhấn "NỘP BÀI" để hệ thống tự động chấm. Code sẽ được tự động lưu lên máy chủ + file Excel.
  • ⭐ Nhấn "Gắn cờ" (ngôi sao) để đánh dấu bài đã học xong — cờ được lưu lại.

3. BÀI KIỂM TRA TRỰC TUYẾN

  • Chọn tab "Kiểm Tra" để xem các đề giáo viên đã giao.
  • Nhấn "Bắt Đầu Làm Bài" — giao diện giống "Thực Hành".
  • ⚠️ Nếu giáo viên KHÔNG cho phép, nút "Xem Code Mẫu" sẽ bị ẩn.

4. SỬ DỤNG AI

  • Robot trợ lý: Biểu tượng robot ở góc màn hình. Nhấp 1 lần để đọc toàn bộ văn bản đang hiển thị; nhấp lần nữa để dừng.
  • Hỏi Gia Sư AI: Nhấn nút "Hỏi Gia Sư AI" (góc phải khung đề bài) hoặc "Phân tích lỗi".
  • Gia sư AI có 3 chế độ: Socratic (gợi mở), Hướng tiếp cận (gợi ý), Phân tích lỗi (debug).

5. CĂN CHỈNH CODE

  • Tab: Nhấn "Tab" để chèn 4 dấu cách.
  • Format: Nhấn "Format" để tự động căn chỉnh thụt lề thông minh theo chuẩn lập trình viên.
  • Copy: Nhấn biểu tượng copy để sao chép toàn bộ code.

6. XEM CODE MẪU & QUÊN MẬT KHẨU

  • Xem Code Mẫu: Nhấn nút "Xem Code Mẫu" ở khối "Robot Hướng Dẫn".
  • Quên mật khẩu: Ở form đăng nhập, nhấn "Quên mật khẩu?". Nhập tên đăng nhập + 1 trong 3 (SĐT / CCCD / Email).
  • Nếu 1 trong 3 khớp → đổi mật khẩu thành công ngay.
  • Nếu không có thông tin nào đúng → hệ thống báo: "Bạn vui lòng chờ Admin cấp lại mật khẩu sau 24 giờ hoặc hãy tạo mật khẩu mới!". Nhật ký ghi "Reset pw" màu đỏ.

7. XUẤT EXCEL BÀI LÀM

  • Giáo viên/Admin có thể xuất Excel 3 sheet: chi tiết từng câu, thống kê theo ngày, tổng hợp học sinh.
  • Code Python của từng học sinh được lưu tự động mỗi khi nhấn NỘP BÀI.
